# Aula Técnica

## Descripción
Este proyecto es una página web básica para presentar servicios académicos y registrar los datos de estudiantes interesados.

## Archivos del proyecto
- `index.html`: contiene la estructura y el contenido de la página.
- `estilos.css`: contiene los colores, tamaños y estilos de la página.
- `script.js`: permite cambiar el título, mostrar un mensaje y responder al envío del formulario.

## Cómo abrir el proyecto
1. Guarda `index.html`, `estilos.css`, `script.js` y `README.md` en la misma carpeta.
2. Abre `index.html` en un navegador web.

## Funciones
- Cambiar el color y el tamaño del título.
- Mostrar u ocultar un mensaje de bienvenida.
- Completar un formulario con nombre, correo, teléfono y programa de interés.
- Mostrar un mensaje cuando el formulario se envía correctamente.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Nota
El formulario es una demostración básica. Los datos no se guardan en una base de datos.
